# Security policy

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Dwijeshh/pcap-crowd-crush-simulation/security/advisories/new) to send details to the repository maintainers. Include the affected version or commit, reproduction steps, and potential impact. Do not disclose exploitable details in a public issue or pull request.

If GitHub does not offer the private report form, open a brief public issue asking maintainers to enable private reporting, without including vulnerability details. Maintainers will review private reports and coordinate a fix and disclosure through GitHub.

This research simulation has no hosted service or security support commitment. The policy covers vulnerabilities in the repository's code and tooling.
